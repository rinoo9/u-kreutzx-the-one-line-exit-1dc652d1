# The One-Line Exit

A one-line resignation letter entry for the make.fun bounty "The One-Line Exit". The program `main.py` writes a single resignation letter to `/output/entry.txt` — a night security guard quitting because the ghosts in aisle four are better company than management, and at least they say goodnight.

> I hereby resign as night security guard — the ghosts in aisle four are better company than management, and they at least say goodnight.

Run it with `python3 main.py`. It asserts the entry is 1–140 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
